## Objetivo do Projeto

Desenvolver uma solução para análise e visualização do ecossistema econômico de São José dos Campos, organizando dados sobre empresas, setores e atividades econômicas.

- Tratamento e organização dos dados;
- Classificação das empresas por setor;
- Criação de gráficos e indicadores;
- Aplicação de filtros;
- Visualização da localização das empresas;
- Desenvolvimento de painel de BI.

## Product Backlog

| Sprint | Objetivo |
|---|---|
| **Sprint 1** | Filtragem, limpeza, padronização e classificação dos dados |
| **Sprint 2** | Desenvolvimento da primeira versão do painel de BI |
| **Sprint 3** | Melhorias, análises, filtros, testes e documentação final |

### Principais User Stories

- Filtrar os dados públicos para São José dos Campos;
- Limpar e padronizar a base de dados;
- Classificar empresas por setor e atividade;
- Criar uma base consolidada;
- Visualizar empresas por segmento;
- Criar filtros e gráficos;
- Visualizar a localização das empresas;
- Comparar setores e oportunidades de trabalho;
- Relacionar empresas, tecnologia e inovação;
- Disponibilizar a base tratada e a documentação.

## Organização das Sprints

### Sprint 1 — Preparação dos dados
Seleção das fontes, filtragem, limpeza, padronização e classificação dos dados.

### Sprint 2 — Painel de BI
Criação dos primeiros gráficos, indicadores, filtros e representação da localização das empresas.

### Sprint 3 — Finalização
Comparações, filtros detalhados, melhorias visuais, testes e documentação.
