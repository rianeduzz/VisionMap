# Código Python — VisionMap

Notebook que gera a base tratada do projeto a partir dos microdados da **RAIS Estabelecimentos** (Ministério do Trabalho e Emprego): filtra São José dos Campos, corrige inconsistências, sinaliza duplicidades, padroniza os campos e classifica os estabelecimentos por setor e atividade.

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/rianeduzz/VisionMap/blob/main/Codigo-Python/rais_sjc_colab.ipynb)

## Como usar

1. Clique no botão **Abrir no Colab** acima.
2. No Colab, salve uma cópia em **Arquivo > Salvar uma cópia no Drive**.
3. Siga a célula **Como usar (passo a passo)** do notebook: baixe a RAIS no PDET, envie o arquivo para o seu Google Drive, preencha o `ANO_BASE` e execute tudo.
4. O Excel e o CSV tratados são salvos na pasta `saida_rais_sjc` do seu Drive.
